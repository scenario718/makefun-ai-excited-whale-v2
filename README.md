# Milk whale erupts from a kitchen sink

A majestic whale made entirely of white milk bursts out of an ordinary
kitchen sink, breaching explosively from the faucet as milk splashes
everywhere. The surreal scale contrast — a huge ocean creature erupting
from a tiny domestic sink — gives the artwork its dynamic, thrilling
energy.

## How the entry works

The artwork lives in `whale.png` (1024×1024 PNG). Running `main.py`
copies `whale.png` to `entry.png` inside the output directory given by
the `MAKEFUN_OUTPUT_DIR` environment variable (default `/output`),
unchanged and byte-identical:

```bash
python3 main.py
```
